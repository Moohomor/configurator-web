# Передача изменений в WebSoft через пакеты

## Создание пакета данных с изменениями в WebSoft

Пакеты позволяют собрать изменённые объекты WebSoft в один файл и передать их на другой стенд или локальный сервер.

Например, в пакет можно добавить:

- настраиваемые Web-шаблоны;
- элементы шаблонов;
- сайты и настройки портала;
- системные события;
- типы и шаблоны уведомлений;
- другие изменённые объекты WebSoft.

### 1. Добавьте нужные объекты в пакет

Откройте в WebSoft HCM Administrator раздел, в котором находится изменённый объект.

Выделите нужную запись, нажмите **правой кнопкой мыши** и выберите:

**Добавить в пакет**

### 2. Настройте параметры добавления объекта

После выбора **«Добавить в пакет»** откроется окно параметров.

В зависимости от типа объекта WebSoft может предложить, например:

- включить в пакет ресурсы, прикреплённые к объекту;
- включить категории, к которым прикреплён объект;
- добавить связанные объекты.

Если выбрано несколько объектов, параметр **«Применить ко всем выбранным объектам»** позволяет применить одинаковые настройки сразу ко всем выбранным записям. Если он выключен, параметры задаются для каждого объекта отдельно.

Нажмите **«Применить»**.

### 3. Добавьте остальные изменённые объекты

Таким же способом добавьте в пакет все остальные объекты, которые должны быть переданы.

Для нашей интеграции 3D-конфигуратора в пакет WebSoft могут входить, например:

1. **Настраиваемый Web-шаблон** — переход к курсу.
2. **Элемент шаблона** с `mode`, через который вызывается Web-шаблон.
3. **Сайт** `Демо-портал. WebSoft HCM`, содержащий пункт меню **«Подвижной состав»**.

> Сам SCORM-курс удобнее передавать отдельно как `configurator-web-scorm2004.zip` и импортировать через раздел электронных курсов.

### 4. Откройте содержимое пакета

В главном меню WebSoft HCM Administrator выберите:

**Содержимое пакета**

Откроется окно **«Объекты пакета»**. В нём отображаются все записи, добавленные на предыдущих шагах.

Перед сохранением проверьте список и убедитесь, что в пакете нет лишних объектов.

### 5. Сохраните полный пакет

В окне **«Объекты пакета»** нажмите:

**Сохранить полный пакет...**

В системном окне выбора файла укажите папку, в которую нужно сохранить пакет.

### 6. При необходимости измените имя файла

WebSoft может автоматически предложить имя, сформированное на основе текущей даты и времени.

При необходимости задайте более понятное имя, например:

```text
tmh_portal_changes.zip
```

После сохранения полученный ZIP-файл можно передать другому участнику команды.

## Импорт пакета данных

На компьютере, куда нужно перенести изменения, должен быть запущен **WebSoft Server** и открыт **WebSoft HCM Administrator**.

### 1. Откройте системное администрирование

В левом меню WebSoft HCM Administrator нажмите значок **шестерёнки**:

**Системное администрирование**

### 2. Перейдите в обработку пакетов

Откройте:

**Системное администрирование → Обработка пакетов**

### 3. Нажмите «Обработать пакет»

В верхней панели нажмите кнопку со знаком **+**:

**Обработать пакет**

### 4. Выберите ZIP-файл

Укажите пакет, который был сформирован на другом WebSoft-сервере через кнопку **«Сохранить полный пакет...»**.

После выбора файла запустите обработку пакета.

### 5. Дождитесь завершения обработки

После успешной обработки в разделе **«Обработка пакетов»** должна появиться новая запись со статусом:

```text
обработан
```

### 6. Проверьте перенесённые изменения

После обработки пакета откройте разделы, объекты которых входили в пакет, и проверьте результат.

Например, для интеграции 3D-конфигуратора:

```text
Портал
→ Сайты
→ Демо-портал. WebSoft HCM
→ Меню
```

Проверьте наличие пункта:

```text
Подвижной состав
```

Если в пакет входили настраиваемый Web-шаблон и элемент шаблона, также проверьте их наличие в **Дизайнере**.

Инструкция со скринами для создания пакета см. https://lifel.ru/hr-tech/hr-platform/update-webcoft-hcm?utm_source «Ручное формирование пакета данных по объектам системы»
